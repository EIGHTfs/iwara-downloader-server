下载流程说明

① 解析视频 ID，每次重新向 Iwara 拉取 fresh 直链（直链会过期，不可复用）
② 按文件名模板生成保存名（默认 Iwara_-_{TITLE}_[{ID}]_[{QUALITY}].mp4）
③ 直连后端：IP 直连 Cloudflare 边缘，失败自动换 CDN 子域并断点续传
④ Aria2 后端：把直链推到 RPC，进度请到 Aria2 WebUI 查看

下载路径与命名

直连后端填本机路径；Aria2 后端填 Aria2 所在机器上的路径。模板不要写 .mp4，保存时自动补扩展名。

可用变量：{TITLE} 标题　{ALIAS} 作者显示名　{AUTHOR} 作者用户名　{ID} 视频 id　{QUALITY} 清晰度（Source / 540 / 360）　{UPLOADTIME} 上传时间　{NOWTIME} 下载时的当前时间

点赞 / 关注

需已登录 Iwara。下载时自动点赞/关注失败不会中断下载。搜索标注依赖接口返回的 liked 字段。

视频索引

      
总表 iwara-index.json：以视频 id 为键，只存作者名/用户名、标题、fileId、时长、tags、上传日。不算 hash。下载目录本机可写则写到那里；Aria2 远程路径写不了时写到服务数据目录。可导入别人 dump，或扫描下载目录 json。
