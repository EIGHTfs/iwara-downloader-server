🎫 Iwara 凭证书签方案（无需装油猴）

手机 Edge / 夸克 / Chrome 不支持油猴脚本目录，用这个「书签小工具」替代：在 iwara 页面点一下书签，弹出凭证面板直接复制。

第 1 步：复制书签代码

点下方按钮复制（或长按文本框全选复制）：

第 2 步：在 Edge 中新建书签
1打开 iwara.tv 任意页面 → 点地址栏旁的 ⭐（添加到收藏/书签）
2点「更多选项 / 编辑」，将刚才复制的代码粘贴到地址（URL）框，替换掉原来的网址
3名称随意（如「iwara凭证」），保存
第 3 步：使用
1打开 www.iwara.tv 并登录（等 Cloudflare 挑战完成、页面加载完）
2点刚创建的书签 → 底部弹出凭证面板
3点「📋 复制 Cookie」/「📋 复制 Token」→ 粘到下载服务器设置页
💡 若提示缺少 cf_clearance：下拉刷新页面（让 Cloudflare 挑战重新完成）后再点书签。
⚠️ Cookie 会过期，失效时重新获取即可。手机与 NAS 建议同一 WiFi（cf_clearance 与 IP 绑定）。
