5. 网页和油猴怎么分工

网页只做三件事：展示服务器账号、给安装入口、收粘贴凭证。

油猴侧约定（网页不要做成相反的）：

  • 点右下角图标立刻弹出，打开面板 / 发送视频 不读 Cookie
  • 用 GET /api/account-check 当「服务器在线 + 账号信息」
  • 服务器已登录：面板只留发送，不展示本机 Cookie/Token
  • 服务器没凭证：才 GM_cookie，再 POST /api/settings 回传
  • 发送：POST /api/receive { url }，服务端规整后走同一套 POST /api/download
  • 用 项目访问密码 自动 POST /api/login，不要另做 send-token
  • 不要书签脚本，不要 /bookmarklet

页头安装按钮：

<a class="ghost" href="/iwara-cred-fetch.user.js" id="btn-userscript">📥 油猴脚本</a>

服务端输出该文件时：

  • Content-Type: text/javascript; charset=utf-8
  • Content-Disposition: inline; filename=iwara-cred-fetch.user.js
  • Cache-Control: no-store
